⚙️ How to install Custom Gloves

Choose and download the glove you want. To install it, you need to replace the original resources.assets file in your game directory.

Common installation path:

... \Steam\steamapps\common\SEUM Speedrunners from Hell\Seum_Data

⚠️ Important: You must select the DEFAULT GLOVE in the game settings for the custom skin to appear!
