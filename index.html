Velocitymeter

What is it?

The Velocitymeter is an advanced plugin for SEUM: Speedrunners from Hell. It provides essential tools to track your speed, angles, and jump height in real-time. Boost your performance with FPS optimization, race ghosts, map shortcuts, and a powerful Level Editor suite.

All features and the download file are listed below.

In Game features

🔥 Meter options:

⚡ Vspeed

Displays both horizontal (hspeed) and vertical (vspeed) velocity.

🏆 PeakSpeed

Display your best peak speed above 12.18.

🔄 Auto Reset Peak

Every time you hit the floor, the peak speed is reset.

📏 Hspd Threshold

Dynamic velocity colors based on custom speed thresholds (Green/Yellow/Red).

⏱️ Calculate Realtime

Displays the precise real-time duration of your current run.

🦘 Jump meter

Display your jump height.

📐 Display X / Y

Shows your precise camera and movement angles.

📊 Last run stats

Show additional information of your last run.

📜 Edit range

Enables a scrollable leaderboard to browse all player replays.

🚀 FPS Boost

Optimizes performance by removing particles, effects, themes, and blood.

👻 Ghost replay

Enable it to see the ghost of any player.

How to use the Ghost feature?

  1. Enable the option in the Velocitymeter menu.
  2. Select a replay from the leaderboard and load it.
  3. Press the Shift key to initialize the ghost data.
  4. Start your run; the ghost will appear automatically.

Note: You can customize the ghost's color and opacity in the settings.

🗺️ Maps Menu:

Secret Levels

Instantly enter any secret level by clicking its number.

Unreleased

Explore official maps that were never publicly released.

Prototypes

Access testing environments and prototype maps.

💡 Game Tips:

Cycles Management

Save and load map cycles.
Press Q to save your current cycle, then use A or Scroll to instantly load it.

Hellikus Solutions

Step-by-step solutions and hints for all Hellikus secrets.

⚙️ Settings:

Custom Resolutions

Set any game resolution, including non-standard aspect ratios.

Keybinds Editor

Fully customize the Velocitymeter menu and feature hotkeys.

Themes & Colors

A complete editor to personalize your menu colors and UI theme.

⚠️ Important: Always press "Save all settings" to apply your changes permanently.

Pre-game Features

📅 Seasons Selector

Access old leaderboards and watch replays from previous seasons.
Note: Official leaderboards prior to Season 7 are no longer available.

📜 Leaderboard Range

Instantly jump to any specific rank. Enter a number in the box above the leaderboard to 'scroll' directly to that position.

Level Editor Enhancements

The plugin expands the editor's capabilities by adding new assets, custom themes, entity counters, and advanced keybinds for a more efficient workflow.

⚠️ Warning: Custom LEE items may cause editor instability. Always save your level before adding them!

Wireframe Mode

Analyze level geometry and hidden paths with the built-in Wireframe toggle.

  • Enable: Press F8
  • Disable: Press F9

Pro Tip: For the best visibility, use this mode with "No Theme" and "No Particles" enabled in the settings.

Download & Installation

⚙️ How to install

  1. Download the Assembly-CSharp.dll file below.
  2. Locate game folder: Steam Library > Right-click SEUM > Manage > Browse local files.
  3. Navigate to SEUM_Data \ Managed.
  4. Backup: Rename the original Assembly-CSharp.dll to .backup.
  5. Replace: Drop the new Assembly-CSharp.dll into the folder.

Press Y in-game to open the menu or F1 for help.

Assembly-CSharp.dll

To uninstall: Delete the modified file and use "Verify integrity of game files" on Steam.
